# Option B — 手動初始化 + 快速追蹤 + 低信心才 OCR

## 套用方式
1. 先備份目前專案中的 `main.py` 和 `video_processor.py`。
2. 將本資料夾的兩個 `.py` 檔覆蓋到原專案同名檔案。
3. 使用原專案的 Python 虛擬環境執行：
   ```bash
   python -m pip install -U opencv-contrib-python numpy PyQt5
   # 只有需要 OCR 補救時才需要：
   python -m pip install easyocr
   python main.py
   ```

## 操作方式
1. 匯入影片，停在你想開始追蹤的影格。
2. 按「手動框選並追蹤」，在彈出的影格用滑鼠框選一個目標，按 Enter。
3. 「目標文字」欄位可留空。若填入文字，只有追蹤與局部模板比對失敗時，才會嘗試 OCR。
4. 追蹤完成後，結果會新增為一個追蹤馬賽克任務，可再調整起訖影格和強度。

## 重要限制
- 這版追蹤的是你手動框選的「單一實體目標」，不是自動找出整段影片所有相同文字/車牌。其他目標請分別建立追蹤任務。
- KCF/MOSSE 沒有穩定的通用信心分數，因此程式用初始外觀模板的相關分數作為近似品質門檻。光線、旋轉、遮擋、透視變形仍可能造成追蹤失敗。
- OCR 補救只在目標附近的局部區域進行，且有冷卻間隔，避免頻繁掃描整張畫面。若目標大幅離開原位置，局部 OCR 可能找不到它。
- 為避免舊框長時間留在錯誤位置，追蹤失敗超過短暫寬限後，該影格不輸出馬賽克框。正式使用前請檢查監控畫面與輸出影片。
- 此版優先使用 KCF；若安裝的 OpenCV 沒有 KCF，會嘗試 MOSSE，再退回 CSRT。建議使用 `opencv-contrib-python`，不要同時安裝 `opencv-python` 與 `opencv-contrib-python` 的不同版本。
